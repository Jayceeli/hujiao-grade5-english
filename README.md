# 沪教版五年级上册英语点读（2026新版）

适用于《义务教育教科书（五·四学制）·英语 五年级上册》。

## 内容

- Starter + Unit 1–10 全册教材文字
- 74 个教材配套原版音轨合并为在线音频 sprite
- 点击每个栏目“原版音频”播放出版社配套音轨
- 点击任意课文句子使用浏览器英语语音逐句点读
- Starter → At school 已完成原版逐句时间轴对齐
- 支持搜索、播放速度、循环播放、iPad/手机/电脑自适应

## 在线发布

GitHub Pages 由 `.github/workflows/pages.yml` 自动部署。

## 文件结构

- `index.html` / `app.js` / `styles.css`：点读网页
- `data/book.json`：教材结构化文字
- `data/audio-sprite-manifest.json`：74 个原版音轨在在线音频 sprite 中的时间位置
- `assets/audio-sprite.ogg`：为网页流量优化的原版音频集合
- `data/markdown/`：Starter 与 Unit 1–10 Markdown
- `全册结构化文字.md`：整册文字汇总

> 教材及配套音频仅用于个人学习。
